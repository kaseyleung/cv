# Kasey 梁幸琪 · Interactive CV

交互式个人简历站。纯静态 HTML / CSS / JS，无需构建步骤。

## 运行

**方式一：直接打开**

双击 `index.html` 即可。页面、字体、影片都能正常显示。

> 3D 模型（`tv3d.glb` 等）在 `file://` 下会被 Chrome 的跨域策略拦截，画面会自动回退成一张「主持现场」照片。想看 3D，用方式二。

**方式二：本地服务器（推荐，3D 模型可正常加载）**

```bash
cd cv
python3 -m http.server 8000
# 打开 http://localhost:8000/index.html
```

macOS 也可以直接双击 `serve.command`，会自动起服务并打开浏览器。

## 页面结构

| 区块 | 内容 |
|---|---|
| Hero | 姓名、主张、关键数据、3D 视觉（或主持现场回退图） |
| 02 Profile | 个人简介 + **15 秒自我介绍影片** + 关键数据 |
| 03 Experience | 工作与项目经历，可按「全部 / 工作 / 项目」筛选，点 + 展开详情 |
| 04 Capabilities | 能力矩阵 + 3D 传播价值模型 |
| 05 Education | 教育背景、奖项、证书与舞台经历 |
| 06 Portfolio | 作品集，可跳转研究页 |
| 07 Contact | 邮箱复制、联系方式 |

## 替换影片

把新视频压成同尺寸，覆盖 `kasey-intro-web.mp4`，再截一张封面覆盖 `kasey-intro-poster.jpg` 即可，无需改代码。
