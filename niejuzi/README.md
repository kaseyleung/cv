# 捏橘子 · NIE JUZI

**公开试玩：** https://kaseyleung.github.io/cv/niejuzi/

90 秒体感反应小游戏：捏住橘子，避开榴莲。

**在线试玩：** https://kaseyleung.github.io/cv/niejuzi/

- 鼠标 / 触控：按下即捏合
- 摄像头模式：双手拇指与食指捏合（需授权；画面只在本地处理）
- 本机排行榜：前 20 名，保存在浏览器 localStorage

单文件游戏页面：`index.html`（图片、字体与代码全部内嵌）。

设计与素材来自《捏橘子》项目文档及参考图；字体 Fusion Pixel 12px (SIL OFL 1.1)；音效由 Web Audio 实时合成。
